# Support policy

> [!NOTE]
> On this page, choose the right support channel and include enough safe detail to reproduce a problem.

Use GitHub issues for reproducible product defects and documentation corrections. Use discussions for usage questions when enabled. Security issues follow [SECURITY.md](SECURITY.md).

Community support is best effort. Include the package version, Salesforce release and edition, operation, safe sample shape, expected result, and actual status or error code. Remove credentials, org IDs, record IDs, and CSV field values.

Unsupported integrations and deferred capabilities are listed in [Unsupported features](docs/reference/unsupported-features.md).
