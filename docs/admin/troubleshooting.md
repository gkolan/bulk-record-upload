# Troubleshooting

> [!NOTE]
> On this page, diagnose common upload, access, configuration, and result problems without exposing record values.

| Symptom                 | Check                                                                              |
| ----------------------- | ---------------------------------------------------------------------------------- |
| Process is unavailable  | Active process Developer Name and active field records                             |
| Not authorized          | Package Permission Set, Custom Permission, object access, FLS, and sharing         |
| Header validation fails | UTF-8 CSV, unique normalized headers, and configured column keys                   |
| Row fails               | `bru_error_code`, safe message, operation access, validation rules, and automation |
| Result is unavailable   | Terminal status, retention period, and Salesforce Files access                     |

Do not paste CSV contents, credentials, org IDs, or sensitive values into public issues.
